# 메이저맵 HRM 직원 온보딩 페이지

`index.html` 하나로 동작하는 정적 페이지입니다. 사내 HRM(웹메일 + 인사)을 처음 쓰는 **일반 직원**이 실제로 쓰는 기능만 담았습니다. 팀장·HR 관리자·슈퍼 관리자 전용 기능은 의도적으로 제외했습니다.

## 보는 방법

- 로컬: `docs/hrm-onboarding/index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.
- 외부 의존성은 전용 서체 Wanted Sans(jsDelivr CDN) 하나이며, 막히면 Pretendard → 시스템 한글 폰트 순으로 대체됩니다.
- 라이트/다크 테마를 모두 지원합니다. 첫날 체크리스트의 체크 상태는 사용자 브라우저(localStorage)에만 저장됩니다.

## 브랜드(BI) 적용

메이저맵 BI 가이드(`[메이저맵]251210 brand identity manual guide_basic`, 2025-12-10)를 따랐습니다.

| 항목 | 적용 |
| --- | --- |
| 로고 | `assets/majormap-symbol-{red,navy,white,black}.svg` 원본 심볼을 인라인 SVG로 사용(상단 바, 푸터, 파비콘). 타이핑·재작도 없음 |
| 배경–로고 조합 | 흰색/Paper 배경 → Red 심볼. 다크 테마는 Navy `#202B45` 계열 배경이므로 규정대로 Red 심볼 유지 |
| 색 | 주색 Red `#EA5645`(버튼·단계 번호·섹션 라벨·링크 밑줄), 텍스트·구분 Navy `#202B45`, 완화·안내 Mint `#90C6B4`(팁 콜아웃, 팀 메일 배지), 배경 Paper `#F6F7F8`. 경고·오류는 브랜드색이 아닌 의미색 |
| 서체 | Wanted Sans 단일 서체. 제목 Bold/ExtraBold, 본문 Regular. 섹션 라벨은 가이드 관례대로 대문자 영문 소형(`02 · MAIL`) |
| 그래픽 모티프 | 히어로 배경에 Red 심볼 확대(투명도 6%), 푸터 Navy 밴드에 Sky Blue 심볼 크롭(투명도 14%). 장식 영역에만 사용 |

미리보기용 아티팩트는 외부 스타일시트를 Google Fonts만 허용하므로 Wanted Sans 링크를 빼고 폴백 서체로 게시합니다. 레포 파일은 Wanted Sans를 그대로 로드합니다.

## 설계 메모

- **구조**: 상단 고정 메뉴 → 히어로(접속 주소, 첫날 체크리스트) → 하루 흐름 5칸 → 기능 섹션 8개 → 빠른 참조 표 → FAQ·용어. 실제 서비스의 왼쪽 사이드바 순서를 따랐습니다.
- **글**: 모든 설명은 "무엇을 하나" 한 줄 → 번호 단계 → 꼭 알아둘 것(콜아웃) 순서입니다. 수치(첨부 64개/3.5MB, 20초 자동 저장, 휴지통 30일, 8시간 = 1일)는 원본 그대로 옮겼습니다.
- **배지**: 원본 매뉴얼의 파란 `운영관리자`, 검은(Navy) `슈퍼 관리자` 배지를 그대로 재현해 "이 탭이 안 보여도 정상"이라는 메시지를 첫 화면에 두었습니다.
- **상호작용**: 접속 주소 복사, 체크리스트(진행률 표시), 현재 섹션 강조, 8단계 투어(키보드 ←/→/Esc 지원), FAQ 접기/펼치기. 외부 스크립트 없이 바닐라 JS입니다.
