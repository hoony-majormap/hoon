# 메이저맵 HRM 직원 온보딩 페이지

`index.html` 하나로 동작하는 정적 페이지입니다. 사내 HRM(웹메일 + 인사)을 처음 쓰는 **일반 직원**이 실제로 쓰는 기능만 담았습니다. 팀장·HR 관리자·슈퍼 관리자 전용 기능은 의도적으로 제외했습니다.

## 보는 방법

- 로컬: `docs/hrm-onboarding/index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.
- 외부 의존성은 Google Fonts(IBM Plex Sans KR, Hahmlet) 하나이며, 폰트가 막혀도 시스템 한글 폰트로 대체됩니다.
- 라이트/다크 테마를 모두 지원합니다. 첫날 체크리스트의 체크 상태는 사용자 브라우저(localStorage)에만 저장됩니다.

## 설계 메모

- **구조**: 상단 고정 메뉴 → 히어로(접속 주소, 첫날 체크리스트) → 하루 흐름 5칸 → 기능 섹션 8개 → 빠른 참조 표 → FAQ·용어. 실제 서비스의 왼쪽 사이드바 순서를 따랐습니다.
- **글**: 모든 설명은 "무엇을 하나" 한 줄 → 번호 단계 → 꼭 알아둘 것(콜아웃) 순서입니다. 수치(첨부 64개/3.5MB, 20초 자동 저장, 휴지통 30일, 8시간 = 1일)는 원본 그대로 옮겼습니다.
- **배지**: 원본 매뉴얼의 파란 `운영관리자`, 검은 `슈퍼 관리자` 배지를 그대로 재현해 "이 탭이 안 보여도 정상"이라는 메시지를 첫 화면에 두었습니다.
- **상호작용**: 접속 주소 복사, 체크리스트(진행률 표시), 현재 섹션 강조, 8단계 투어(키보드 ←/→/Esc 지원), FAQ 접기/펼치기. 외부 스크립트 없이 바닐라 JS입니다.
