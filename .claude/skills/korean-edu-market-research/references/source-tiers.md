# 소스 신뢰도 등급

## 등급 기준

| 등급 | 기준 | 리포트 취급 |
|---|---|---|
| A | 공급자 공식 페이지 또는 교육청 신고 기반 집계 사이트에서 가격·시수를 직접 확인. 18개월 이내 | 본문 수치로 사용 |
| B | 보도자료, 공식 SNS, 리뷰 블로그 등 2차 소스. 또는 시수를 추정한 경우 | 본문 사용하되 플래그 표기 |
| C | 검색 스니펫만 있고 원문 미확인, 날짜 불명, 또는 18개월 초과 | 본문 제외, 부록에만 기재 |

## 병합 단계의 자동 판정 (`pipeline.py merge`)

최종 등급 = 아래 중 **가장 낮은 것**: Dissector 자기 판정, 규칙 등급, Verifier 권고.

| 조건 | 규칙 등급 | 플래그 |
|---|---|---|
| `published_at == "date_unknown"` | C | `date_unknown` |
| `checked_at` 기준 18개월 이상 경과 | C | `stale` |
| `source_type == "snippet"` | C | `snippet_only` |
| `source_type` ∈ press / sns / blog | B | `secondary_source` |
| `hours_estimated == true` | B | `hours_estimated` |
| 시간당 원가 계산 불가 | C | `pph_unavailable` |
| Dissector의 시간당 값이 재계산값과 1% 넘게 차이 | (등급 영향 없음) | `pph_recomputed` |

`source_urls`가 비었거나 스키마 위반인 레코드는 등급을 매기지 않고 **제외**한다. 제외 항목도 출처 확인 비율의 분모에 들어간다 (숨기지 않기 위해).

## 출처 확인 비율

```
출처 확인 비율 = 본문(A/B) 레코드 수 ÷ (본문 + 부록 + 제외)
```

70% 미만이면 `check`가 FAIL — 그 리포트는 완성이 아니라 위험물이다.

## 신선도 판단 요령 (Dissector용)

- 페이지에 찍힌 게시일·수정일, 모집 공고의 기수(예: "2026년 가을학기"), 수강 기간 중 가장 최근이면서 **가격과 같은 문맥에 있는 날짜**를 쓴다.
- 사이트 푸터의 저작권 연도(© 2026)는 발행일이 아니다.
- 교육기관은 지난 기수 공지를 내리지 않는다. 검색 상위라고 현재 공지가 아니다.
- 날짜를 못 찾으면 지어내지 말고 `date_unknown`.
